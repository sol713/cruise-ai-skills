# Port-Day Time Buffers

Use these planning buffers before all-aboard time. Increase the buffer when the user is risk-averse, traveling with kids, has mobility needs, or is a first-time cruiser.

## Minimum Return Buffers

| Port-Day Pattern | Minimum Buffer | Use When |
|---|---:|---|
| Walkable port area | 45-60 minutes | Activity is near the pier and easy to abandon |
| Simple taxi beach or city visit | 75-90 minutes | One transfer each way, flexible return |
| Independent tour with local pickup | 90 minutes | Provider gives explicit pickup and return timing |
| Tender port | 120 minutes | Tender queues can delay both directions |
| Ferry-dependent plan | 120-150 minutes | Ferry status controls return timing |
| Long-distance attraction | 150+ minutes | Transfer exceeds 60 minutes each way |
| Border crossing or mainland transfer | 150+ minutes | Multi-step recovery is hard if delayed |
| Mobility needs or young kids | Add 30 minutes | Transitions, bathrooms, boarding, and walking take longer |

## Timeline Pattern

Use this structure in every output:

1. Ship arrival.
2. Realistic ship-clearance delay.
3. Leave ship.
4. Start activity.
5. Begin return.
6. Back near port.
7. All aboard.

## Conservative Defaults

When the user gives only arrival and all-aboard times:

- Assume ship clearance takes 30-45 minutes.
- Do not schedule independent pickup earlier than 45 minutes after arrival.
- Do not schedule a non-official activity that returns inside the minimum buffer.
- Prefer shorter, nearby activities when the total port window is under 6 hours.
