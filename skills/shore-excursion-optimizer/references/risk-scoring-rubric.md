# Return-to-Ship Risk Scoring Rubric

Use this rubric to make port-day recommendations consistent. It is a planning model, not live safety data.

## Risk Factors

Add points for each factor that applies:

| Factor | Points | Notes |
|---|---:|---|
| Activity is within easy walking distance of the pier | 0 | Applies only when the traveler can walk back without relying on transport |
| One simple taxi or rideshare transfer each way | 1 | Add more if return transport is uncertain |
| Transfer is 30-60 minutes each way | 2 | Traffic exposure matters more near all-aboard time |
| Transfer is over 60 minutes each way | 3 | Usually avoid unless official or very early |
| Tender port | 2 | Tender queues can compress the true port window |
| Ferry or water taxi dependency | 3 | Ferry delay can remove all recovery options |
| Border crossing, mainland transfer, or multi-leg transport | 3 | Complexity multiplies timing risk |
| Tour ends less than 90 minutes before all aboard | 3 | Use 120+ minutes for risk-averse travelers |
| Activity cannot be shortened once started | 2 | Examples: boat trip, ruins tour, long hike |
| Weather-sensitive activity | 1 | Snorkeling, small boats, exposed trails |
| First-time cruisers, young kids, mobility needs, or medical constraints | 1 | Add if the group needs slower transitions |
| Provider does not clearly state pickup, return, cancellation, and cruise timing terms | 3 | Treat as high risk until verified |

## Rating Thresholds

| Score | Rating | Recommendation Meaning |
|---:|---|---|
| 0-2 | Low | Suitable if live timing confirms the plan |
| 3-5 | Medium-low | Usually fine with a conservative return buffer |
| 6-8 | Medium | Needs a strong reason, backup plan, and live verification |
| 9-11 | High | Prefer official excursion or a simpler plan |
| 12+ | Avoid | Do not recommend unless official and explicitly timed for the ship |

## Overrides

Use these overrides even if the point score looks acceptable:

- If the plan cannot preserve the minimum return buffer, rate it `High` or `Avoid`.
- If the user is low-risk and the plan uses tender, ferry, or 60+ minute transfers, recommend official or a closer alternative.
- If all-aboard time is missing, do not give a firm recommendation.
- If live weather, ferry, road, or provider return terms are unknown for a same-day plan, state that the risk rating is provisional.
